Frequently Asked Questions

Everything you want to know about BEBO the PET — the free AI desktop assistant for Windows.

Is BEBO the PET really free?
Yes, completely free forever. BEBO is open source under the MIT license. There is no subscription, no premium tier, and no hidden cost. The AI runs on Groq's free tier which gives you 1,000 free requests per day — that's roughly 40 AI tasks every hour, all day.
What's new in BEBO 2.0?
A lot! New AI brain — GPT-OSS 120B with an automatic GPT-OSS 20B backup when the primary is busy. A color for every action button. Dark / light theme toggle. Remappable keyboard shortcuts from the panel's ⚙ settings. Voice input via Windows dictation (Win+H). Multi-monitor support — BEBO wakes on the screen you're using. And update alerts right inside the panel.
Do I need a credit card?
No. You only need a free Groq API key, which requires no credit card. Creating the key takes about 30 seconds at groq.com.
What AI model does BEBO use?
BEBO uses GPT-OSS 120B, OpenAI's open-weight large language model, served through the Groq API at ~500 tokens per second — roughly 5x faster than GPT-4o. For everyday productivity tasks the output quality is equivalent to the best paid models.
Is my data stored anywhere?
No. BEBO is completely stateless. Your text goes directly from your machine to the Groq API and the answer comes back. Nothing is logged, stored, or used for training by BEBO. There is no account and no cloud storage. The only exception: an optional anonymous install counter — one daily ping carrying the app version and a random id, never your text. Turn it off anytime from the panel's ⚙ settings.
What are the system requirements?
Windows 10 or Windows 11, about 200 MB of disk space, and an internet connection for AI requests. BEBO is lightweight and uses minimal RAM while idle on your desktop.
How do I get a Groq API key?
Go to groq.com, create a free account (no card needed), open the API Keys section and click Create API Key. Copy it and paste it into BEBO's setup screen. Full steps on the download & setup page.
How fast is BEBO compared to ChatGPT in a browser?
A complete BEBO workflow takes 3–4 seconds: click the pet, paste text, pick an action, get the result. The same task through a browser AI tool takes 12–15 seconds. See the full speed comparison.
What can BEBO actually do?
Six built-in AI functions: Summarize any text, Humanize AI-written text, Simplify complex text, Draft Email from rough notes, Fix Grammar silently, and Ask AI anything in free form. Details on how it works.
What keyboard shortcuts does BEBO have?
Three global shortcuts that work inside any app: Ctrl+Shift+W wakes BEBO, Ctrl+Shift+B hides BEBO, and Ctrl+Shift+P shows or hides the assistant panel. Since BEBO 2.0, all three can be remapped from the ⚙ settings inside the panel.
Can I dictate text instead of typing?
Yes. Click into BEBO's Input box, press Win+H, and speak — Windows' built-in voice typing writes your words straight into the box. No extra setup, no extra cost. That's also why BEBO's hide shortcut moved to Ctrl+Shift+B — to keep everything around Win+H friction-free.
Is BEBO open source?
Yes. The full source code is public at github.com/bhavik8025/BEBO-the-PET under the MIT license. You can read the code, report issues, or contribute.
Why does Windows SmartScreen show a warning when I install?
Code-signing certificates cost hundreds of dollars per year, which an independent free app does not pay for. The warning only means the publisher is not registered with Microsoft — not that anything is wrong. Click More info → Run anyway. The source code is fully public on GitHub so you can verify exactly what BEBO does.
Does BEBO work offline?
The pet itself runs offline, but the AI functions need an internet connection because GPT-OSS 120B runs on Groq's cloud servers, not on your machine.
Can BEBO start automatically with Windows?
Yes — the installed version of BEBO adds itself to Windows startup automatically. No setup needed. Manual alternative: press Win+R, type shell:startup, and place a BEBO shortcut in that folder.
Will there be a macOS version?
A macOS port is on the long-term roadmap. BEBO is built with Electron which is cross-platform, so the core already works — the remaining work is macOS-specific window behavior and packaging.
