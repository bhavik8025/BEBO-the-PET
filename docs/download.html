Setup in 4 Steps

1

Download BEBO

Get BEBO.the.PET.Setup.exe (installer) or the portable EXE from the official GitHub releases page. GitHub is the only official download source.

2

Run the installer

Double-click the EXE. If Windows SmartScreen appears, click More info → Run anyway (see the note below on why this happens). BEBO installs in seconds.

3

Get your free Groq API key

Visit groq.com → create a free account (no credit card) → open API Keys → click Create API Key → copy it.

This key gives you 1,000 free AI requests per day on GPT-OSS 120B.

4

Paste key & launch

Paste the key into BEBO's setup screen and click Verify & Launch. BEBO appears in the corner of your desktop — click it and you're ready.

⚠ About the Windows SmartScreen warning

Code-signing certificates cost hundreds of dollars per year — an independent free app doesn't pay that. The warning only means the publisher isn't registered with Microsoft, not that anything is wrong. BEBO's entire source code is public on GitHub, so you can verify exactly what it does before running it.

Optional: Start BEBO with Windows

★

Pin to Windows startup

Press Win + R → type shell:startup → press Enter → place a BEBO shortcut in the folder that opens. BEBO will now start automatically every time Windows boots.
