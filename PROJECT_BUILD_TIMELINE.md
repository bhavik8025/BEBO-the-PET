# Desktop AI Pet Assistant - Build Timeline

Saved on 2026-05-11 for project reference.

## Practical Estimate

- Basic working version: 2 to 3 days
- Solid local MVP: 5 to 7 days
- Polished living pet experience: 2 to 3 weeks
- True custom sprite/pet-pack quality: 3 to 5 weeks depending on assets

## Phase 1 Goal

Create the Electron foundation:

- Transparent always-on-top pet overlay
- Draggable pet
- Click-through idle support
- Compact assistant panel
- IPC bridge between pet, panel, and main process
- System tray
- Global shortcuts
- Simple animated SVG pet placeholder

## Recommended Build Order

1. Make the pet appear, float, drag, and open the panel.
2. Connect quick action task flow.
3. Add AI task execution and clipboard support.
4. Add screenshot + OCR explain-screen flow.
5. Add SQLite history and settings.
6. Polish animation, personality, and packaging.
